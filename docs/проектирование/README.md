# Проектирование системы StartApp

Эта папка содержит UML-диаграммы и модели проектирования системы StartApp, созданные в соответствии с методологией Unified Process (UP).

## 📋 Структура документации

1. **[01-Модель-предметной-области.md](./01-Модель-предметной-области.md)**
   - Диаграмма классов предметной области
   - Описание сущностей и их атрибутов
   - Ключевые ассоциации между сущностями

2. **[02-Модель-прецедентов.md](./02-Модель-прецедентов.md)**
   - Диаграмма прецедентов
   - Детальное описание всех прецедентов системы
   - Основные и альтернативные потоки

3. **[03-Модель-проектирования.md](./03-Модель-проектирования.md)**
   - Системные диаграммы последовательностей
   - Диаграмма классов проектирования
   - Описание операций и их постусловий

## 🔄 Взаимосвязь артефактов

Следующая диаграмма показывает взаимосвязь между артефактами проектирования:

```
Модель предметной области
    ↓
    Объекты, атрибуты, ассоциации
    ↓
Модель прецедентов
    ↓
    Системные события
    ↓
Системные диаграммы последовательностей
    ↓
    Системные операции
    ↓
Описание операций
    ↓
Модель проектирования
```

## 📊 Основные сущности

- **Пользователь** — может быть создателем проекта и участником
- **Проект** — публичный проект (учебный/коммерческий)
- **Отклик** — отклик пользователя на проект
- **ТегТехнологии** — справочник технологий
- **ПользовательТехнология** — связь пользователя с технологией и грейдом
- **ПроектТехнология** — требуемые технологии проекта
- **Рекомендация** — автоматическая рекомендация проекта
- **ПаспортПроекта** — детальное описание проекта

## 🎯 Ключевые прецеденты

1. Регистрация и вход
2. Создание профиля
3. Управление технологиями
4. Создание проекта
5. Просмотр проектов
6. Отклик на проект
7. Просмотр откликов
8. Оценка кандидата (автоматическая)
9. Принятие/отклонение отклика
10. Получение рекомендаций
11. Умный подбор стека (для учебных проектов)
12. Просмотр паспорта проекта

## 🛠️ Технологии проектирования

Диаграммы созданы с использованием **Mermaid** — это позволяет:
- Просматривать диаграммы в GitHub
- Редактировать диаграммы как текст
- Интегрировать в документацию

Для просмотра диаграмм используйте:
- GitHub (автоматический рендеринг)
- VS Code с расширением Mermaid (см. [КАК-СМОТРЕТЬ-ДИАГРАММЫ.md](./КАК-СМОТРЕТЬ-ДИАГРАММЫ.md))
- Онлайн редактор: [mermaid.live](https://mermaid.live)

📖 **Подробная инструкция:** [КАК-СМОТРЕТЬ-ДИАГРАММЫ.md](./КАК-СМОТРЕТЬ-ДИАГРАММЫ.md)

## 📝 Примечания

- Все диаграммы созданы на русском языке в соответствии с требованиями
- Модели соответствуют методологии Unified Process
- Диаграммы будут обновляться по мере развития проекта
