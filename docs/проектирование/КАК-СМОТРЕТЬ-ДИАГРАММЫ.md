# Как просматривать диаграммы Mermaid в IDE

## 🎯 VS Code (рекомендуется)

### Вариант 1: Markdown Preview Mermaid Support

1. Откройте VS Code
2. Перейдите в **Extensions** (Ctrl+Shift+X или Cmd+Shift+X)
3. Найдите и установите расширение:
   - **"Markdown Preview Mermaid Support"** от Matt Bierner
   - Или **"Mermaid Preview"** от vstirbu
4. Откройте любой `.md` файл с диаграммами
5. Нажмите **Ctrl+Shift+V** (или Cmd+Shift+V на Mac) для предпросмотра
6. Диаграммы Mermaid будут автоматически отрендерены!

### Вариант 2: Mermaid Editor

1. Установите расширение **"Mermaid Editor"** от Tomoyuki Aota
2. Откройте файл с диаграммами
3. Нажмите **Ctrl+Shift+P** (или Cmd+Shift+P)
4. Введите "Mermaid: Preview" и выберите команду
5. Диаграмма откроется в отдельной панели

### Вариант 3: Markdown Preview Enhanced

1. Установите расширение **"Markdown Preview Enhanced"** от Yiyi Wang
2. Откройте `.md` файл
3. Нажмите правой кнопкой мыши → **"Markdown Preview Enhanced: Open Preview to the Side"**
4. Диаграммы будут отрендерены автоматически

## 🔧 Настройка VS Code

Если диаграммы не отображаются, проверьте настройки:

1. Откройте настройки VS Code (Ctrl+,)
2. Найдите "markdown preview"
3. Убедитесь, что включен рендеринг Mermaid

Или добавьте в `settings.json`:

```json
{
  "markdown.mermaid.enabled": true,
  "markdown.preview.breaks": true
}
```

## 🌐 Онлайн просмотр

### Mermaid Live Editor

1. Откройте [mermaid.live](https://mermaid.live)
2. Скопируйте код диаграммы из файла (блок между ` ```mermaid ` и ` ``` `)
3. Вставьте в редактор
4. Диаграмма отобразится справа

### GitHub

Если ваш проект на GitHub:
1. Просто откройте файл `.md` на GitHub
2. GitHub автоматически рендерит все Mermaid диаграммы
3. Не требуется никаких дополнительных действий!

## 📱 Другие редакторы

### IntelliJ IDEA / WebStorm

1. Установите плагин **"Mermaid"** из Marketplace
2. Откройте `.md` файл
3. Диаграммы будут отображаться в предпросмотре

### Obsidian

1. Obsidian имеет встроенную поддержку Mermaid
2. Просто откройте файл в Obsidian
3. Диаграммы отобразятся автоматически

## 🚀 Быстрый старт (VS Code)

**Самый простой способ:**

1. Установите расширение: **"Markdown Preview Mermaid Support"**
2. Откройте файл: `docs/проектирование/01-Модель-предметной-области.md`
3. Нажмите: **Ctrl+Shift+V** (Windows/Linux) или **Cmd+Shift+V** (Mac)
4. Готово! Диаграммы отображаются в предпросмотре

## ❓ Проблемы и решения

### Диаграммы не отображаются

- Убедитесь, что расширение установлено и включено
- Перезапустите VS Code
- Проверьте синтаксис Mermaid (должен быть в блоке ` ```mermaid `)

### Диаграммы отображаются как код

- Убедитесь, что используете правильный формат:
  ` ```mermaid ` (не просто ` ``` `)
- Проверьте, что расширение активно
