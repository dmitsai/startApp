## 💡 Идея проекта

StartApp — это платформа для поиска команды для IT-стартапов, где каждый пользователь может:
- Создать профиль с тегами технологий и уровнем знаний (0-10)
- Создавать публичные проекты с детальным паспортом
- Откликаться на проекты и получать рекомендации
- Для учебных проектов — автоматический подбор оптимального стека технологий

## 🎯 Основные возможности

- ✅ Профили пользователей с системой тегов и грейдов
- ✅ Создание и управление проектами
- ✅ Система откликов и оценки кандидатов
- ✅ Рекомендательная система проектов
- ✅ Умный подбор стека для учебных проектов

## 🛠️ Технологический стек

Проект разрабатывается на **T3 Stack**:
- **Frontend:** Next.js, TypeScript, React Query, React Hook Form, Animate UI, Tailwind CSS
- **Backend:** tRPC, Prisma, PostgreSQL
- **Преимущества:** Полная типобезопасность end-to-end, единая кодовая база, отличный DX

Подробнее о стеке и настройке проекта см. в [PROJECT.md](./PROJECT.md) и [SETUP.md](./SETUP.md).
