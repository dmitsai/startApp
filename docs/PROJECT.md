## 📋 Описание проекта

**StartApp** — веб-приложение для поиска и формирования команды для учебных и коммерческих IT-стартапов. 

**Ключевая особенность:** Платформа построена на принципе равенства ролей — каждый пользователь может быть одновременно и **создателем проекта** (основателем стартапа/рекрутером), и **участником** (соискателем). Разработчик может создать свой проект и искать команду, а также откликаться на проекты других пользователей. Это универсальная экосистема для взаимного поиска и формирования IT-команд.

---

## 🎯 Целевая аудитория

### Основные пользователи:
Все пользователи платформы могут выполнять **двойную роль** — создавать проекты и участвовать в проектах других:

- **Студенты и начинающие разработчики** — могут создавать учебные проекты и искать команду, а также присоединяться к проектам для практики и обучения
- **Опытные разработчики** — могут быть основателями коммерческих стартапов, создавать проекты и подбирать команду, а также участвовать в интересных проектах других
- **Основатели стартапов** — разработчики, которые хотят запустить свой проект и найти команду, при этом могут также участвовать в других проектах
- **Преподаватели и менторы** — создают учебные проекты для студентов, могут также участвовать в других образовательных инициативах

**Важно:** Нет разделения на "только рекрутеров" и "только соискателей" — каждый пользователь имеет равные возможности.

## 🚀 Основной функционал

### 1. Профиль пользователя
- **Теги технологий** с грейдом (0-10):
  - `0` — хочу выучить
  - `1-3` — базовые знания
  - `4-6` — средний уровень
  - `7-9` — продвинутый уровень
  - `10` — углубленное знание
- **CV/Резюме** для оценки компетенций
- **История проектов** и отзывы
- **Двойная роль:** Профиль используется как для создания проектов (как основатель), так и для участия в проектах (как соискатель)

### 2. Создание проекта
- **Любой пользователь может создать проект** — нет ограничений по ролям
- **Публичный проект** с описанием и требованиями
- **"Паспорт проекта"** включает:
  - Название и описание
  - Цели и задачи
  - Необходимый стек технологий
  - Роли и требования к участникам
  - Тип проекта (учебный/коммерческий)
  - Сроки и этапы
  - Контакты и коммуникация
- **Создатель проекта** автоматически становится участником своей команды, но может также откликаться на другие проекты

### 3. Система откликов
- **Любой пользователь может откликаться на проекты** других пользователей
- **Создатель проекта** (который сам может быть участником других проектов) видит:
  - **Оценку проекта** — насколько кандидат подходит
  - **Валидность участника** — проверка соответствия требованиям
  - **Рекомендации** на основе CV и тегов
- Пользователь может одновременно быть создателем одного проекта и участником другого

### 4. Умный подбор (для учебных проектов)
- **Автоматический выбор стека технологий** из кандидатов
- Анализ навыков участников
- Рекомендация наиболее сильного и обучающего стека
- Оптимизация для максимального обучения

### 5. Рекомендательная система
- **Пул рекомендаций проектов** на основе:
  - CV пользователя
  - Тегов и грейдов технологий
  - Истории проектов
  - Интересов и целей развития

## 🏗️ Архитектура

### Frontend (Next.js App Router)
- **Серверные компоненты** — для SEO и производительности
- **Клиентские компоненты** — для интерактивности
- **React Query** — кэширование и синхронизация данных
- **React Hook Form** — формы с валидацией
- **Animate UI** — анимированные компоненты интерфейса
- Адаптивный дизайн с Tailwind CSS

### Backend (tRPC + Next.js)
- **tRPC роутеры** — типобезопасные API endpoints
- **Prisma ORM** — работа с базой данных
- **Middleware** — аутентификация, валидация, логирование
- Система рекомендаций (алгоритмы подбора команды)

### База данных (PostgreSQL + Prisma)
- **Схема данных:**
  - Профили пользователей
  - Проекты и их паспорта
  - Отклики и оценки
  - История взаимодействий
  - Теги технологий и грейды
- **Миграции Prisma** — версионирование схемы БД

### Типобезопасность
- **Единая типизация** через TypeScript и tRPC
- **Автодополнение** в IDE для всех API вызовов
- **Валидация на этапе компиляции** — меньше runtime ошибок

## 🛠️ Технологический стек

Проект разрабатывается на **T3 Stack** — современном стеке для full-stack разработки с TypeScript.

### Frontend
- **Next.js** — React-фреймворк с SSR и App Router
- **TypeScript** — типизированный JavaScript
- **React Query (TanStack Query)** — управление серверным состоянием и кэширование
- **React Hook Form** — управление формами с валидацией
- **Animate UI** — UI-библиотека с анимациями ([animate-ui.com](https://animate-ui.com/docs/installation))
- **Tailwind CSS** — utility-first CSS фреймворк

### Backend
- **tRPC** — end-to-end типизированные API без генерации кода
- **Prisma** — современный ORM для работы с базой данных
- **PostgreSQL** — реляционная база данных
- **Next.js API Routes** — серверная часть на Next.js

### Инфраструктура и инструменты
- **TypeScript** — единая типизация для frontend и backend
- **tRPC** — обеспечивает типобезопасность между клиентом и сервером
- **Prisma Client** — типобезопасный доступ к базе данных

### Дополнительно (планируется)
- Система рекомендаций (ML алгоритмы)
- Аутентификация (NextAuth.js / Auth.js)
- Файловое хранилище (для CV) — AWS S3 / Cloudinary / Vercel Blob
- Деплой — Vercel (frontend + API) + отдельная БД (Supabase / Railway / Neon)

### Преимущества T3 Stack
- **Типобезопасность end-to-end** — TypeScript + tRPC обеспечивают полную типизацию от БД до UI
- **Единая кодовая база** — frontend и backend в одном проекте
- **Отличный DX** — автодополнение, валидация на этапе компиляции
- **Современный стек** — актуальные технологии и лучшие практики
- **Быстрая разработка** — меньше boilerplate кода, больше фокуса на бизнес-логике
