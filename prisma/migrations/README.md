# Миграции базы данных StartApp

## 📋 Описание схемы

Схема базы данных создана на основе документации проекта и модели предметной области.

### Основные модели:

1. **User** - Пользователи (расширенная модель с NextAuth)
2. **TechnologyTag** - Справочник технологий
3. **UserTechnology** - Связь пользователь-технология с грейдом (0-10)
4. **Project** - Проекты (учебные/коммерческие)
5. **ProjectTechnology** - Требуемые технологии для проекта
6. **ProjectRole** - Роли в проекте
7. **ProjectMember** - Участники проекта
8. **Application** - Отклики на проекты
9. **Recommendation** - Рекомендации проектов для пользователей

## 🚀 Создание миграции

Когда база данных будет запущена, выполните:

```bash
# Создать миграцию
npx prisma migrate dev --name init_startapp_schema

# Или если база уже существует и нужно применить изменения
npx prisma migrate deploy
```

## 📝 Применение миграции

```bash
# Разработка (создает миграцию и применяет)
npx prisma migrate dev

# Production (только применяет существующие миграции)
npx prisma migrate deploy

# Генерация Prisma Client
npx prisma generate
```

## 🔄 Откат миграции

```bash
# Откатить последнюю миграцию
npx prisma migrate resolve --rolled-back <migration_name>
```

## 📊 Структура данных

### User (Пользователь)
- Базовая информация (name, email, image)
- Расширенный профиль (bio, cvUrl, role, location)
- Связи: проекты, отклики, технологии, участник проектов

### TechnologyTag (Технология)
- Название, категория, описание
- Связи с пользователями и проектами

### UserTechnology (Навыки пользователя)
- Грейд 0-10
- Уникальная связь пользователь-технология

### Project (Проект)
- Полный паспорт проекта
- Тип (EDUCATIONAL/COMMERCIAL)
- Статус (DRAFT/OPEN/IN_PROGRESS/COMPLETED/CLOSED)
- Связи: технологии, отклики, участники, роли

### Application (Отклик)
- Сопроводительное письмо
- Оценка соответствия (matchScore)
- Статус (PENDING/ACCEPTED/REJECTED)
- Детальная оценка (scoreBreakdown)

### Recommendation (Рекомендация)
- Оценка релевантности
- Обоснование
- Флаг просмотра

## 🎯 Индексы

Схема включает оптимизированные индексы для:
- Поиска по email и name пользователей
- Фильтрации проектов по статусу, типу, дате создания
- Поиска откликов по проекту, пользователю, статусу
- Рекомендаций по пользователю и оценке

## ⚠️ Важно

- Все связи используют `onDelete: Cascade` для автоматической очистки
- Уникальные ограничения предотвращают дубликаты
- Enum типы для типобезопасности
